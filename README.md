# 声乐教学喉部模型 3D 演示版

> 我想让每个普通人学得起唱歌。——刘伟晨

一个免费公开（源码可见）的声乐教学工具：**3D 喉部解剖模型 + 肌肉功能演示 + 第1课理论通关测试**。整个工具放在一个文件夹里（`index.html` + `lib/`），下载后可离线使用，不用安装。

## 它能做什么

### 3D 喉部模型
- 真实解剖网格（喉软骨、声带、喉内肌、悬吊肌），可点击任意结构查看知识卡
- 甲状软骨半透明——隔着软骨看清内部声带与肌肉的层次

### 肌肉功能演示（点选六块喉内肌后「演示这块肌肉」）
- **环甲肌 / 甲杓肌**：音高拮抗——拉长变薄 ⇄ 缩短变厚
- **环杓侧肌 / 杓横肌 / 杓斜肌**：声带闭合三种力
- **环杓后肌**：声门打开（呼吸位）
- 每块肌肉演示：暖橙=发力收缩，蓝=被牵伸，青绿=等长锚定

### 声带闭合与声区
- 良好闭合（六肌协作联动演示）
- 三种典型错误闭合：弓形（漏气）/ 后部裂隙 / 沙漏形（声带小结）
- 胸声 / 头声形态对比

### 第1课理论通关测试
- 15 道多选题，答对 12 题获得通关证书
- 答错即时讲解，支持回看、重测
- 题库参考《嗓音解剖》《歌唱动力学》编写，仅作教学练习；不代表这两本书及其作者的认证、推荐或背书

## 快速开始

**方式一：在线访问（推荐）**

直接打开公开网址 **<https://liu-vibecoder.github.io/vocal-larynx-3d/>**（GitHub Pages 托管，国际线路，国内较慢）；国内学生实际在用的入口是 **<http://122.51.183.126/>**（访问更快）。电脑、手机都能用，不用下载、不用安装。自建站点的做法见 `DEPLOY.md`。

**方式二：本地离线（要起一个本地静态服务器）**

先把整个文件夹下载完整：`index.html` 和 `lib/` 两个都不能少（只拿 `index.html` 一个文件，3D 一定起不来）。

1. 在这个文件夹里打开 PowerShell（在资源管理器地址栏输入 `powershell` 回车即可）；
2. 执行一行命令——
   - 装了 Python 的：`python -m http.server 8080`
   - 没装 Python、但有 Node.js 的：`npx serve .`
3. 浏览器打开 `http://localhost:8080/`。

> **不要直接双击 `index.html`。** 以 `file://` 方式打开时，浏览器会拦截 ES 模块（3D 引擎）的加载，3D 区只会显示加载失败提示；文字、知识卡、题库仍可用，但模型出不来。这是浏览器的安全限制，不是文件坏了。

## 使用提示

- 左侧面板点结构名 = 显示/隐藏该结构
- 点击 3D 模型上的结构 = 高亮 + 知识卡
- 双击六块演示肌 = 直接演示该肌功能
- 页面右上角「🎤 点击此处进行理论测试」进入答题
- 手机端可用（触摸旋转/缩放，答题已做移动端优化）
